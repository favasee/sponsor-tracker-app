# Impeccable Design Skill

The Impeccable framework ensures code generated by AI avoids aesthetic mediocrity ("AI slop") and meets the standards of world-class design engineering.

## 1. The Anti-Slop Directives

1. **No Gratuitous Multi-Colored Gradients**:
   - Avoid generic purple-to-blue or rainbow gradients for standard card backgrounds.
   - Use subtle, single-family radial glows or tonal shifts with low opacity (e.g., `bg-amber-500/5` blur).
2. **Deliberate Visual Hierarchy**:
   - Every screen has ONE dominant focal point (e.g. Primary Action or Hero Metric).
   - Secondary elements must recede with proper opacity and font sizing, not compete for attention.
3. **No Unanchored Floating Elements**:
   - Every card, pill, and container must have a defined border (`border border-white/[0.08]`) to anchor it on dark backgrounds.
4. **Content-Informed Sizing**:
   - Never truncate text unnecessarily when space allows.
   - Truncated text must always include a native browser `title` or tooltip.

## 2. Execution Standards

* **Depth through Layering**:
  - Layer 0: Canvas (`#07080C`)
  - Layer 1: Frosted Surface (`bg-white/[0.03] backdrop-blur-2xl border-white/[0.08]`)
  - Layer 2: Elevated Interactive Card (`hover:bg-white/[0.06] hover:border-amber-500/30`)
  - Layer 3: Modal & Overlay (`bg-[#0f1219] shadow-2xl border-white/15`)
* **Interaction Polish**:
  - Buttons: include `active:scale-[0.98]` and `transition-all duration-150` for tactile response.
  - Hover states should slightly lighten backgrounds (`hover:bg-white/[0.12]`) rather than shifting layout dimensions.
